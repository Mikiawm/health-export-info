Health Export Privacy Policy

Health Export is intended for use by its owner. With the owner's permission, it reads selected Google Health data, such as step counts, workouts, heart rate, and sleep, to generate weekly reports.

Reports are intended for the owner's private Obsidian vault and its private GitHub repository. The public website contains information about the tool. It does not display health reports or request access to visitor accounts.

If the export runs in GitHub Actions, GitHub processes the data to generate the report, and OAuth credentials are stored in GitHub Actions secrets. Google Health data is used only for the owner's reports. It is not sold or used for advertising.

The owner can stop future exports by revoking access in Google Account connections. Existing reports remain under the owner's control and can be deleted from the vault and its Git history.
